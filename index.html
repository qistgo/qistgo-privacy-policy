QistGo Privacy Policy

Last updated: September 26, 2026

QistGo is a personal expense and balance tracking app designed to help users monitor their personal finances, records, and daily transactions. The app is designed to store user data locally on the device.

Data Stored Locally

QistGo may store records entered by the user, including wallet balances, transactions, personal contacts, amounts, notes, app settings, and a local passcode. This data is stored strictly on the user's device.

Backup and Import

If the user chooses to create a backup or import a database file, the selected file is handled only for that user-requested action. Backup files are saved to the location selected by the user.

Data Collection and Sharing

QistGo does not collect, sell, rent, or share user data with advertising networks, analytics providers, external servers, or third parties. The app does not require a user account and operates completely offline.

Security

QistGo provides a local passcode feature to help protect access to the app. Users are responsible for keeping their device, passcode, and backup files secure.

Contact

For privacy questions, contact AHMED HASAN HAMMOOD at QistGo@outlook.sa.

سياسة الخصوصية لتطبيق QistGo

آخر تحديث: 26 سبتمبر 2026

تطبيق QistGo هو أداة شخصية لتتبع الأرصدة والمصروفات والمعاملات اليومية لمساعدة المستخدم في إدارة شؤونه المالية الخاصة. صُمم التطبيق لحفظ بيانات المستخدم محلياً على الجهاز.

البيانات المخزنة محلياً

قد يخزن QistGo السجلات التي يدخلها المستخدم، مثل أرصدة المحافظ، الحركات المالية، الأسماء الشخصية، المبالغ، الملاحظات، إعدادات التطبيق، ورمز الدخول المحلي. تُحفظ هذه البيانات حصرياً على جهاز المستخدم.

النسخ الاحتياطي والاستيراد

إذا اختار المستخدم إنشاء نسخة احتياطية أو استيراد ملف قاعدة بيانات، يتم التعامل مع الملف فقط لتنفيذ الإجراء الذي طلبه المستخدم. يتم حفظ ملفات النسخ الاحتياطي في المكان الذي يختاره المستخدم.

جمع البيانات ومشاركتها

لا يقوم QistGo بجمع أو بيع أو تأجير أو مشاركة بيانات المستخدم مع شبكات إعلانية أو مزودي تحليلات أو خوادم خارجية أو أطراف ثالثة. لا يتطلب التطبيق إنشاء حساب مستخدم ويعمل بدون إنترنت تماماً.

الأمان

يوفر QistGo ميزة رمز دخول محلي للمساعدة في حماية الوصول إلى التطبيق. يتحمل المستخدم مسؤولية حماية جهازه ورمز الدخول وملفات النسخ الاحتياطي.
